# Reproducing the paper

This directory reproduces the figures and numbers of the binaryfog paper. It is not part of the installed package;
the scripts import binaryfog from `../src`.

## Entry points

There are two, and both can be started from any directory:

```bash
export PY=python3 PY_HOLODECK=/path/to/holodeck/python BINARYFOG_NG15_MODELS=/path/to/models
bash run_figures.sh             # about ten minutes
JOBS=28 bash run_scans.sh       # of order a day on a 28-core node
```

- `run_figures.sh` builds the figures and numbers from the stored scan outputs in `scans/`. It writes the
  figures to `plots/`, under the file names the paper uses, the tables and numbers to `results/` and the printed
  output of each step to `logs/<step>.log`.
- `run_scans.sh` reruns the scans themselves. It overwrites the files in `scans/`, so `git diff` shows whether a
  rerun reproduces them. Each numbered block can be run on its own.

`PY` is a Python with binaryfog's dependencies, matplotlib and pandas. `BINARYFOG_NG15_MODELS` points at the
model files of the NANOGrav 15-year new-physics search (PTArcade), needed for cosmic superstrings, inflation and
domain walls. `PY_HOLODECK` is a Python with [holodeck](https://github.com/nanograv/holodeck) 1.7.1 (see
`../training/README.md`), needed for the steps of `run_scans.sh` that run holodeck itself.

## Layout

| directory | contents |
|---|---|
| `scripts/` | the Python scripts, one per figure, table or scan, and the modules they share |
| `inputs/library/` | the holodeck libraries behind the surrogate: `lib6d_*.jsonl`, 2000 population models with 2000 realisations each; `cont_*.jsonl`, the same models without realisation scatter; `qlib.jsonl`, the realisation quantiles of 150 models held out of the fit, generated by `build_quantile_library.py` |
| `inputs/pta/` | the NANOGrav 15-year free spectra (`freespec/`) and the digitised contours of figure 9 of the erratum to the NANOGrav astrophysics paper |
| `inputs/` | the Standard Model degrees of freedom (`geff_SM.dat`) and the logo |
| `scans/` | the outputs of `run_scans.sh` |
| `plots/`, `results/`, `logs/` | written by `run_figures.sh`, not tracked |

## Prior sets

The scripts name the astrophysical prior sets of table 1 as the package does: `nanograv`, `tomczak_kormendy`,
`survey_average` and `flat`. Scan files under the NANOGrav priors carry no prior-set tag; the others carry
`_tomczak_kormendy`, `_survey_average` or `_flat`. The environment variable `PRIOR_SET` selects the set in
`run_scan_marginal.py` and `repair_scan.py`.
